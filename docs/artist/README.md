# Aliya 模型扩展需求（给画师 / 绑定师）

对象：`aliya.cmo3`（Cubism Editor 5.3 工程，与仓库 `redesign/ui/assets/live2d/aliya/16.moc3` 同源）。
目标：补上桌宠动作需要的骨骼和头顶特效。动作文件、程序接入、测试由开发方完成，
画师只需改模型并按本文导出。

## 必须遵守（否则现有程序会出错）

- **不改动、不删除、不改名任何现有参数、部件和网格。** 程序按 ID 读写，
  例如 `ParamArmL01`、`Param30`、`Param37`、`Part21`（猫耳，有显示开关）、`ArtMesh12`（💢）。
- **不改现有参数的范围和默认值。** 新增内容只能是新参数、新变形器、新网格。
- **所有新参数默认值必须是「没有效果」**，即默认姿态和现在完全一样。
- 不改变默认姿态下人物的外轮廓。程序按默认姿态计算窗口大小、点击区域和脚底位置。
- 新增的显示类参数（特效）只允许取 0 或 1，不要在中间值做渐变图层。
  程序会在 0 和 1 之间直接切换，有渐变时中间帧会出现半透明重叠。
  如果特效需要出现动画（弹出、放大），请另做一个形变参数（见下文）。
- 只用一张贴图（与现在相同），尺寸不超过 2048。
- 现有 `16.moc3` 是 moc3 格式版本 4，程序内置 Cubism Core 6.0.1。若用 5.4 编辑，
  导出时选与现有文件相同或更低的 moc3 版本，交付前由开发方用程序加载确认。

## 一、头顶特效（8 个，素材已备好）

素材在 `effects/`，透明底 PNG，最长边 512px。生成时以模型里现有的 💢 为风格参照：
无描边，同色相的双色调，左上浅、右下深，边缘带轻微手绘起伏。
效果预览见 `effects-preview.png`，最后一个是原有 💢，用来对比大小和风格。

| 文件 | 用途 | 新参数 ID | 建议位置 |
| --- | --- | --- | --- |
| `music.png` | 哼歌、开心 | `ParamFxMusic` | 头顶右上，马尾前方 |
| `sweat.png` | 尴尬、紧张 | `ParamFxSweat` | 右侧太阳穴（画面右，头发外侧） |
| `zzz.png` | 困倦、打瞌睡 | `ParamFxSleep` | 头顶右上，略高于音符 |
| `heart.png` | 喜欢、飞吻 | `ParamFxHeart` | 头顶右上 |
| `exclaim.png` | 吃惊 | `ParamFxSurprise` | 头顶右上 |
| `question.png` | 疑惑 | `ParamFxQuestion` | 头顶右上，可贴近猫耳 |
| `sparkle.png` | 得意、灵光一现 | `ParamFxSparkle` | 头顶右上 |
| `gloom.png` | 沮丧（竖线） | `ParamFxGloom` | 额头正上方，刘海之上 |

每个特效的做法（照现有 💢 `Param32` 的做法）：

1. 用「导入 PSD（追加）」把 PNG 作为新图层导入，放进现有「表情」部件 `Part4`，
   或新建一个「特效」部件。
2. 自动生成网格即可，不需要精细网格。
3. 新建显示参数，范围 0 到 1，默认 0：0 时不透明度 0，1 时不透明度 1。
4. 把特效挂在头部的旋转变形器下，跟随头部的 X、Y、Z 转动。猫耳附近的特效不要跟随猫耳物理。
5. 大小参照预览图，与原 💢 的视觉大小接近（约占头宽的 18%～22%）。
6. 绘制顺序放在头发和猫耳之上。
7. 可选：再加一个 `ParamFxPop`（0 到 1，默认 0），给所有特效做一个统一的
   「从 70% 弹到 100%、略微上浮」形变，程序会用它做出现动画。

如果你觉得某个素材的风格不对，可以直接重画。只要求无描边、双色调，大小和位置接近，
参数 ID 不变。

## 二、骨骼（按优先级）

现有模型的腿没有绑定，身体不能整体上下移动，手臂只能贴身收肘或微微外展，
所以现在的动作只能靠头身晃动。下面按优先级列出需要补的内容。

### P1 身体整体上下位移与压扁：`ParamBodyPosY`

- 范围 -10 到 10，默认 0。
- 正值：整个人向上抬（跳起），最高约 1/12 身高。负值：身体下沉。
  -10 时有落地压扁的效果：躯干变矮变宽，膝盖微屈，头稍微下沉。
- 鞋底在负值时保持贴地，正值时整体离地。
- 用途：开心跳、吓一跳、落地。

### P2 腿部：`ParamLegL`、`ParamLegR`

- 各自范围 -10 到 10，默认 0。
- 正值：该侧抬腿，大腿前抬、屈膝。负值：该侧向后踢（小幅）。
- 两侧交替使用时能做出原地踏步。外套下摆遮挡的地方请处理好。

### P3 手部姿势（替换图层，各自范围 0 到 1，默认 0）

| 参数 ID | 姿势 |
| --- | --- |
| `ParamPoseChin` | 右手托腮（思考） |
| `ParamPoseCover` | 双手捂脸（害羞），手指间露出眼睛 |
| `ParamPoseHips` | 双手叉腰（得意） |
| `ParamPoseBehind` | 双手背在身后（撒娇、乖巧） |

- 做法与现有挥手 `Param30` 相同：1 时显示新手臂，隐藏原手臂。
- 中间值可以做抬手过渡的形变，但同一时刻只会开一个姿势。
- 手臂需要跟随身体转动（`ParamBodyAngleX/Y/Z`）。

### P4 猫耳独立动作：`ParamEarL`、`ParamEarR`

- 各自范围 -1 到 1，默认 0。
- 正值：耳朵竖起、向前。负值：耳朵向后贴（飞机耳，表示委屈或生气）。
- 现有猫耳物理输出（`Param7` 到 `Param14`）继续保留。新参数叠加在物理之上，
  不要接进物理的输入。
- 程序已经支持这两个 ID，模型里有了就会自动启用，不需要改代码。

## 三、交付

- 交付修改后的 `aliya.cmo3`，以及导出的运行时文件：
  - `16.moc3`
  - `16.model3.json`
  - `16.physics3.json`
  - `16.cdi3.json`
  - `aliya.2048/texture_00.png`
- 导出名称不变，直接覆盖仓库里的同名文件。
- 新参数请在 cdi3 里填中文显示名，放进对应分组：特效放「表情」组，`ParamBodyPosY` 和腿放「身体」组。
- 不需要做动作文件（motion3.json），动作由开发方编写。
- 交付后开发方会检查：所有新参数的默认值都没有效果；默认姿态的外轮廓不变；
  现有 14 个动作和 12 个表情都正常；特效在 0 和 1 时显示正确。

## 五、后续：用编辑器接口辅助绑定

Cubism 5.4 给外部集成接口加了编辑命令（新增参数、变形器、部件等）。截至 2026-11，
5.4 正式版尚未发布，alpha 已于 2026-10-18 停用；5.3 的接口只能读写参数值。
5.4 的接口仍不能新建网格、编辑网格顶点或保存导出，所以导入素材、切网格、调关键形状、
导出仍需在编辑器里手动完成。具备 5.4 与 PRO 后，开发方可以用接口代办新增参数、
建变形器、挂层级这类重复操作，并核对参数契约。
