# 眼部表情修复交接记录（2026-09-06）

## 用户范围

- 开心切到无语／受击时，旧眼睛变白遮挡，一段时间后恢复。
- 现有表情不易区分；将剩余的模型表情状态用于合适的现有表情。
- 保留此前哈欠去除异常哭眼和窗口／视线修复。

## 已定位的复现与修复

`face-probe.html?transition=1&legacy=1` 可复现修复前的开心闭眼切换遮挡。
旧实现虽将 EyeOpen 固定为 1、EyeSmile 固定为 0，但普通眼眶、眼珠和
高光的物理摆锤仍残留闭眼变形；PhysicsSetting10/11 在后续帧继续写入。

`face-variant.ts` 现在在物理后隔离这套普通眼部变形，并把特殊眼型视线
归中。Param33/34/35 始终互斥 0/1，分别对应受击／难过／无语；在物理前
固定普通眼睑、笑眼输入，在最终写入点确保不被动作、互动或物理覆盖。
清除表情后恢复普通眼睛、眨眼与视线。哈欠不激活哭眼。

原生流泪接入“难过”，不增加表情数量。开心改为闭眼笑、得意单眼眨眼、
困倦窄眼低头、害羞泛红偏头，其他表情强化眉嘴和轻微头部姿态。
生成器和生成的 JSON 同步保存；生成器不再被 Git 忽略。
